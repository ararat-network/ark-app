# ark-app

The Ark app: one app, mobile first, that holds the wallet and everything a member of
[Ark](https://github.com/ararat-network/ark) does, with the signer as a package of it. The
[tooling direction](https://github.com/ararat-network/ark/blob/main/docs/direction/TOOLING_DIRECTION.md#ark-app) says
what the app is for and where it sits among Ark's repositories.

Nothing is built yet. [docs/DESIGN.md](docs/DESIGN.md) is the design the first commit follows: what the app is, the
repository's shape, the signer package, security, the open decisions, and the build order.
